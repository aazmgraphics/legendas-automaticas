# 🎬 Legendas Automáticas  
Gerador de legendas em tempo real usando Inteligência Artificial  
Compatível com **Python 3.12**

O **Legendas Automáticas** é uma ferramenta desenvolvida em Python 3.12 capaz de **transcrever áudio** e gerar **legendas sincronizadas no formato SRT** com alta precisão.

Ideal para criadores de conteúdo, editores de vídeo, professores, podcasters e profissionais que precisam automatizar legendas.

---

## 🚀 Funcionalidades

- 🎧 **Transcrição em tempo real**  
  O texto aparece na interface conforme o áudio é processado.

- 📝 **Exportação automática para .SRT**  
  Formato padrão utilizado em editores de vídeo.

- 🤖 **Reconhecimento de fala com IA (Whisper)**  
  Totalmente offline (modelo local).

- 🪟 **Interface gráfica em Tkinter**  
  Projetada para ser simples, limpa e funcional.

- 🛠️ **Otimizado e testado em Python 3.12**  
  Compatível com Windows, Linux e macOS.
